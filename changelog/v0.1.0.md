# v0.1.0 - Initial Production Release

This release marks the transition from a prototype to a production-ready, header-only utility library for 3D coordinate system transformations.

## Key Changes

### Core Library & Architecture
- **Header-Only Split**: Logically split the monolithic core into smaller, focused headers: `types.h`, `ratio.h`, `meta.h`, `converter.h`, `presets.h`, and the optional `io.h`.
- **Class-Level Precision**: Templated `TransformationConverter<T>` for consistent precision (float/double) across operations.
- **Determinant-Based Handedness**: Handedness is derived directly from the sign of the basis determinant (`sign(permutation) * dir_r * dir_f * dir_u`) - a branch-free `constexpr` one-liner that is the definition of orientation, not a heuristic.
- **Compile-Time Converters**: `TransformationMeta`, `TransformationMetaBuilder`, and the `TransformationConverter` constructor are all `constexpr`, so converters can be built at compile time as well as from runtime/deserialized data.
- **Composition & Inversion**: `TransformationConverter::inverse()` returns the reverse converter; `a.then(b)` composes two converters (validating that the intermediate coordinate systems match).
- **3x3 Matrix Support**: `convert_matrix` now also accepts 3x3 matrices, treating them as pure rotation/linear transforms (no scaling applied).
- **Stateless & Immutable**: Removed stateful caching from metadata, ensuring pure value-type behavior.
- **Zero Overhead**: Fully header-only architecture with optimized mapping logic and return-by-value overloads.

### Developer Experience (DX)
- **TransformationMetaBuilder**: A fluent builder for expressive coordinate system definitions.
- **Custom Literals**: Added intuitive string literals like `"X+"_a` and `"Y-"_a` for defining axis alignments.
- **Improved Error Messages**: Implemented `static_assert` inside the `Traits` system to provide clear, actionable compile-time errors for missing specializations; the concepts also require a `::type` alias so an incomplete trait fails as a clean constraint mismatch.
- **Less Trait Boilerplate**: `VectorAccessByIndex` / `QuaternionAccessByIndex` CRTP mix-ins synthesise the named component accessors from a single `get_idx` / `set_idx` pair.
- **Text Output**: `to_string(...)` overloads for `Axis`, `AxisDirection`, `Handedness`, `AxisAlignment`, and `TransformationMeta`; opt-in `<base-transformation/io.h>` adds matching `operator<<`.
- **Common Presets**: Added `Presets` namespace with factory methods for `Unity()`, `Unreal()`, `ROS()`, and `OpenGL()`.

### Performance & Flexibility
- **Batch Conversions**: Introduced `convert_points` and `convert_sizes` using `std::span` for efficient batch processing and compiler auto-vectorization.
- **No-Exceptions Mode**: Added `TRANSFORMATION_NO_EXCEPTIONS` support for environments where exceptions are forbidden - invalid input now reports to `stderr` and `abort()`s (a `[[noreturn]]` handler) instead of asserting and falling through to a bogus value.
- **Improved `Ratio`**: Added a real default constructor (`1/1`), removed an uncallable constructor template, and simplified validation.

### Build & Integration
- **Namespaced Targets**: Migrated to a cleaner `Transformation::Core` and `Transformation::Plugins` naming convention.
- **Package Version File**: `project(VERSION 0.1.0)` plus a generated `base-transformation-config-version.cmake`, so `find_package(base-transformation 0.1)` works.
- **Ninja Presets**: Added `ninja` / `ninja-tests` configure presets alongside the Visual Studio ones.
- **Graceful PCL Fallback**: When `USE_PCL` is on but PCL is not installed, the build warns and continues without the PCL plugin instead of hard-failing later.
- **vcpkg Port**: Created a full `vcpkg` port with optional features for Eigen and PCL support.
- **Configured Headers**: Implemented `plugins.h.in` to bake build-time plugin selection directly into the installed headers using numeric values (`#if 1/0`) to avoid global macro clashes (`USE_EIGEN`, `USE_PCL`).
- **CI/CD**: Added a GitHub Actions workflow for automatic Doxygen documentation deployment to GitHub Pages (path-filtered; also indexes the plugin headers).

### Plugins
- **Eigen & PCL Support**: Specialized traits for seamless integration with industry-standard math libraries.

### Testing
- Comprehensive test suite including exhaustive handedness validation, double-precision checks, and batch conversion verification.
